# Project Task

## Build a Personal Profile Console App

Create a Python program that collects and displays information about a person using the skills from Learning Path 1-6.

### Requirements
- Use at least 5 variables with different data types:
  - string
  - integer
  - float
  - boolean
  - list or dictionary
- Use string concatenation to build a bio message.
- Use at least 3 arithmetic operators (`+`, `-`, `*`, `/`, `%`, `**`).
- Show the type of at least 2 variables using `type()`.
- Convert values using type casting, such as:
  - `str()`
  - `int()`
  - `float()`
- Use a dictionary to store profile information.
- Print a final summary like:
  - "Hi, my name is John Doe. I am 29 years old, 1.75 meters tall, and I am a graduate."

### Bonus
- Add a simple menu or welcome message.
- Use a list of hobbies.
- Calculate age, BMI, or total monthly expenses.

### Submission idea
Save the file as:
`personal_profile_app.py`

### Goal
This project should show that you understand:
- variables and naming
- strings and concatenation
- operators
- data structures
- type conversion
